# Evidence

`root-session-proof.txt` preserves the terminal output captured at the successful privilege transition on 25 October 2026. It demonstrates the process identity, capability sets, SMACK context, and running kernel command line at that moment.

It is evidence for one process on one boot of one device. It does not demonstrate persistence, unrestricted filesystem access, safe autoroot, a complete privacy configuration, or compatibility with another unit.

Private device identifiers, local network addresses, signing material, and unrelated application output are intentionally not included in this public repository.
